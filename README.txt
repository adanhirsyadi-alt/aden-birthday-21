BIRTHDAY WEBSITE — ADEN 21 DELUXE

Tema: Timeless Memories / cinematic midnight + warm gold.

Fitur:
- Opening/preloader cinematic
- Hero dengan orbit light
- Smooth reveal animation
- 4 foto kenangan masa kecil
- Klik foto -> fullscreen lightbox
- Timeline perjalanan
- Amplop surat interaktif yang bisa dibuka
- Ucapan ulang tahun ke-21
- Ucapan selamat atas gelar sarjana
- Celebration finale + confetti
- Responsive khusus HP
- Tombol sound dengan ambient tone sederhana (tanpa file musik eksternal)

Cara pakai:
1. Ekstrak ZIP.
2. Buka index.html.
3. Untuk QR sungguhan, upload folder ini ke layanan hosting statis.
4. Setelah mendapat URL publik, buat QR Code yang mengarah ke URL tersebut.

Catatan:
- Jika ingin musik asli, letakkan file MP3 di assets/music.mp3 lalu script dapat diubah untuk memutarnya.
- Foto sudah termasuk dalam folder assets.


MUSIK:
- assets/birthday-ambient.mp3 adalah musik instrumental original yang dibuat khusus untuk website ini.
- Musik mulai ketika tombol "Open the story" ditekan, karena browser HP biasanya memblokir autoplay tanpa interaksi.

QR CODE:
- QR_CODE_TEMPLATE.png disertakan sebagai template.
- QR final yang langsung membuka website TIDAK bisa dibuat secara valid sebelum website memiliki URL publik.
- Setelah folder di-host dan URL publik tersedia, QR dapat diganti dengan QR yang mengarah langsung ke URL tersebut.
